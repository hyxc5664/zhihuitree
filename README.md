# zhihuitree
智慧树网页端视频脚本，需要python环境，selenium库自行下载。
登录界面需要手动填写，不能有其他窗口覆盖在网页上面。代码中适配的是firefox浏览器，如没有需在代码第37行自行修改。自动倍速静音后续会添加。
由于在播放视频后30到90分钟会有一次人机验证，需要手动点击，当然只有这一次。
